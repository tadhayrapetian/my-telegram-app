# Instagram Follower Tracker

Программа для отслеживания **реального** числа подписчиков в Instagram.

Instagram на странице профиля показывает округлённое число («1,2 млн»),
а этот трекер запрашивает внутренний web-API Instagram и получает точное
значение — например, `1 203 417`. Каждая проверка сохраняется в историю,
поэтому видно, сколько подписчиков прибавилось или убыло.

Работает на чистом Python 3.8+, **без установки библиотек**.

## Версия с окном (проще всего)

На macOS достаточно дважды щёлкнуть по файлу **«Запустить трекер.command»** —
откроется окно программы: вводите аккаунт, нажимаете «Проверить», видите
точное число подписчиков, прирост/убыль и историю проверок. Есть галочка
автообновления (каждые 30 мин / час / 3 часа / 6 часов).

При первом запуске macOS может не открыть файл двойным щелчком
(«неустановленный разработчик») — тогда нажмите на файл **правой кнопкой →
«Открыть» → «Открыть»**. Это нужно только один раз.

Запуск вручную: `python3 app.py`.

### Кто подписался и кто отписался (с никами)

В окне есть кнопка **«Показать, кто подписался и отписался»**. Она берёт
полный список ваших подписчиков, сравнивает его с прошлым разом и
показывает ники пришедших (зелёным) и ушедших (красным) — по ним можно
кликнуть и открыть профиль.

Эта функция **требует входа в аккаунт** (переменная `IG_SESSIONID`, см.
ниже) и надёжно работает **для вашего собственного аккаунта**. Чужой
список подписчиков Instagram не отдаёт. При первом нажатии список просто
сохраняется как точка отсчёта; разница появится при следующих проверках.

### Про «обновлять каждые 3 секунды»

Так делать нельзя: Instagram считает частые запросы поведением бота и
блокирует аккаунт (ошибка 429), иногда — надолго. Поэтому самый частый
режим в программе — раз в минуту, и даже он рискованный при отслеживании
списка подписчиков. Для числа подписчиков разумно раз в 5–15 минут, для
списка с никами — ещё реже (раз в час и т. п.).

## Версия для терминала

## Быстрый старт

```bash
cd instagram-tracker

# одна проверка
python tracker.py check instagram

# проверять каждый час (Ctrl+C — выход)
python tracker.py watch instagram --interval 3600

# посмотреть накопленную историю с дельтами
python tracker.py history instagram
```

Пример вывода:

```
@instagram (Instagram)
  Подписчики: 689 152 407  (+1 523 📈)
  Подписки:   131
  Посты:      8 011
  Проверено:  2026-07-16T12:00:00+00:00
```

История хранится в `instagram-tracker/history/<username>.json` — обычный
JSON, его легко открыть в Excel/Sheets или построить график.

## Уведомления в Telegram (необязательно)

Если задать переменные окружения, трекер будет присылать сообщение при
каждом изменении числа подписчиков:

```bash
export TG_BOT_TOKEN="123456:ABC..."   # токен вашего бота от @BotFather
export TG_CHAT_ID="123456789"         # ваш chat_id (узнать: @userinfobot)

python tracker.py watch instagram
```

## Если Instagram блокирует запросы

Анонимные запросы Instagram иногда ограничивает (ошибки 401/403/429).
В этом случае:

1. Откройте instagram.com в браузере, войдите в аккаунт.
2. В DevTools (F12) → Application → Cookies скопируйте значение `sessionid`.
3. Задайте его переменной окружения:

```bash
export IG_SESSIONID="ваше_значение_sessionid"
python tracker.py check instagram
```

Также помогает просто увеличить интервал проверок — скрипт не позволяет
проверять чаще, чем раз в 5 минут, именно чтобы не попасть под лимиты.

## Запуск по расписанию (cron)

Вместо режима `watch` можно запускать разовую проверку по cron —
надёжнее для постоянного мониторинга:

```
0 * * * * cd /path/to/instagram-tracker && python3 tracker.py check instagram >> tracker.log 2>&1
```

## Ограничения

- Работает с **публичными** профилями (закрытые — только с `IG_SESSIONID`
  аккаунта, у которого есть доступ).
- Используется неофициальный эндпоинт web-версии Instagram: при слишком
  частых запросах Instagram может временно ограничить доступ. Разумный
  интервал — от 1 часа.
