# Ритм — лендинг (бежево-оливковая версия)

Одностраничный сайт по мотивам rytmspace.com в бежево-оливковой палитре.
Один файл `index.html` — вся вёрстка, стили и скрипты внутри, внешних запросов нет,
поэтому страница полностью работает офлайн.

## Как открыть на макбуке

Самый простой способ — дважды кликнуть по `index.html`, он откроется в браузере.

Если хочется поднять локальный сервер (например, чтобы открыть с телефона в той же сети):

```bash
cd rytm-landing
python3 -m http.server 8000
```

Затем открыть http://localhost:8000

## Палитра

Все цвета вынесены в CSS-переменные в начале файла (`:root`) — поменять оттенок можно
в одном месте.

```
Бежевые:   #FBF9F3  #F6F2E7  #EFE9D8  #E4DCC5  #D5CAAC
Оливковые: #E7EADA  #CBD3B4  #A9B688  #8A9A63  #6E7F49  #5C6B3C  #47522E  #2B3220
Текст:     #262A1E  #4A5040  #767B67
```

Шрифты — системные (San Francisco на macOS + Iowan Old Style для курсивных акцентов),
поэтому ничего не подгружается из интернета.

## Важно про содержимое

Сам сайт rytmspace.com из среды, где собиралась эта версия, был недоступен
(домен закрыт сетевым прокси), поэтому структура и тексты восстановлены по описанию
продукта: клиенты, занятия, оплаты, абонементы с авторасчётом, drag-and-drop расписание
с цветовыми статусами и историей переносов, просмотр остатка клиентом по ссылке.

Цифры в блоке статистики, цены в тарифах, имена в макетах и отзыв — **демонстрационные**,
их нужно заменить на реальные перед любым публичным использованием.
