# CRM преподавателя английского

Учёт учеников, занятий, абонементов, оплат и материалов. Всё работает на вашем
компьютере: база — обычный файл SQLite в папке программы, никакого облака
и никаких внешних сервисов. Интерфейс на русском, открывается в браузере.

---

## Установка на macOS

### Шаг 1. Проверьте, есть ли Python

Откройте **Терминал** (Spotlight → «Терминал») и выполните:

```bash
python3 -V
```

Если увидели номер версии (`Python 3.11.9` или похожий, **3.9 и новее**) — всё есть,
переходите к шагу 2.

Если написано «command not found» — скачайте Python с
[python.org/downloads](https://www.python.org/downloads/), откройте загруженный
файл и пройдите установку кнопкой «Продолжить». Это разовое действие.

### Шаг 2. Разрешите запуск программы

Один раз выдайте файлу запуска права. В Терминале перейдите в папку с программой
и выполните:

```bash
cd путь/до/teacher-crm
chmod +x start.command
```

Подсказка: вместо того чтобы печатать путь вручную, наберите `cd `, а потом
перетащите папку из Finder прямо в окно Терминала — путь подставится сам.

### Шаг 3. Запустите

Дважды кликните по файлу **`start.command`** в Finder.

Откроется окно Терминала, программа сама поставит всё необходимое (только при
первом запуске, примерно минута) и **сама откроет браузер** на нужном адресе.

> Если macOS скажет, что файл из интернета и не может быть проверен: кликните
> по `start.command` правой кнопкой → **Открыть** → в диалоге ещё раз **Открыть**.
> Это требуется только один раз.

**Важно:** окно Терминала должно оставаться открытым, пока вы работаете —
это и есть сервер программы. Закрыли окно или нажали Control+C — программа
закрылась. Данные при этом никуда не денутся.

### Каждый следующий запуск

Просто двойной клик по `start.command`. Ничего доустанавливать уже не нужно.
Адрес по умолчанию: `http://127.0.0.1:8765` (если порт занят, программа возьмёт
следующий свободный и откроет браузер на нём).

## Что внутри

**Сводка** — занятия на сегодня и ближайшие, кто должен денег, какие абонементы
на исходе, доход по месяцам, сколько занятий и часов проведено.

**Ученики** — список с поиском по имени, уровню и целям. В карточке ученика:
контакты, уровень, регулярное расписание, цели и особые задачи (IEP), заметки,
абонементы, оплаты, материалы и журнал занятий.

**Календарь** — неделя и месяц. Клик по занятию открывает карточку, клик по дате
в месяце показывает эту неделю. Занятие можно создать сразу на несколько недель
вперёд полем «Повторять недель».

**Абонементы** — покупка на любое число занятий с датой окончания и ценой.
Занятие списывается, когда вы отметили его проведённым. Отмена возвращает
занятие в абонемент. Когда остаётся два занятия или меньше семи дней до конца
срока, абонемент попадает в предупреждения на сводке.

**Переносы** — занятие переносится на другую дату с указанием причины. Исходное
остаётся в истории со статусом «перенесено», новое ссылается на него, и в обеих
карточках видно, откуда и куда переехало занятие.

**Оплаты** — сумма, дата, способ, статус (оплачено или ожидается), привязка
к абонементу. Задолженность считается сама: начислено (абонементы плюс разовые
проведённые занятия) минус оплачено.

**Материалы** — ссылки и файлы до 50 МБ, привязанные к ученику и занятию.
Файлы лежат в `data/files/`.

**Настройки** — валюта, длительность занятия по умолчанию, ваше имя, выгрузка
в CSV и резервные копии.

## Данные и резервные копии

Всё лежит в папке `data/` внутри программы:

```
data/crm.sqlite3     — база
data/files/          — загруженные материалы
data/backups/        — резервные копии
```

**Настройки → Сделать копию** создаёт копию базы одной кнопкой. Хранятся последние
тридцать. Копию стоит делать раз в неделю, а саму папку `data/` — иногда
копировать на флешку или в облачную папку: это защищает от поломки диска.

Восстановление: закройте программу, замените `data/crm.sqlite3` нужной копией
из `data/backups/`, запустите снова.

**Выгрузка в CSV** — в настройках отдельные кнопки для учеников, занятий,
абонементов, оплат и материалов. Файлы открываются в Numbers и Excel.

## Как устроено внутри

```
teacher-crm/
  start.command        запуск на macOS
  requirements.txt     зависимости (fastapi, uvicorn, python-multipart)
  app/
    main.py            приложение и статика
    db.py              схема SQLite, настройки, резервные копии
    logic.py           расчёты: остаток абонемента, задолженность, карточка
    routers/           students, lessons, packages, payments, materials, dashboard
  static/
    index.html         каркас страницы
    styles.css         оформление
    app.js             весь интерфейс
  data/                база, файлы, копии (создаётся при первом запуске)
```

Запуск для разработки, без launcher:

```bash
python3 -m venv .venv
.venv/bin/pip install -r requirements.txt
.venv/bin/python -m uvicorn app.main:app --reload --port 8765
```

Документация по API: `http://127.0.0.1:8765/api/docs`.

Переменная `CRM_PORT` задаёт порт, `CRM_DATA` — папку с данными (удобно, чтобы
запустить вторую копию на тестовых данных, не трогая рабочую базу).
