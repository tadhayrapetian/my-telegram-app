# Проверки

Сквозные тесты: поднимают сервер на отдельной базе, дёргают API и прокликивают
интерфейс в настоящем браузере. Нужен Node с установленным Playwright.

```bash
node tests/crm1.test.js   # ученики и календарь
node tests/crm2.test.js   # абонементы, списание, отмена, перенос
node tests/crm3.test.js   # оплаты и задолженности
node tests/crm4.test.js   # материалы, сводка, CSV, резервные копии
node tests/crm5.test.js   # кабинет ученика, переписка, фото
```

Каждый тест работает на временной папке (переменная `CRM_DATA`), рабочую базу
в `data/` не трогает.
