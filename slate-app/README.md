# Slate — рабочая программа для репетитора

Учёт учеников, занятий и оплат. Один файл `index.html`, без сервера и установки,
работает офлайн. Языки: English / Русский / Հայերեն, переключатель слева внизу.

## Как запустить на макбуке

**Быстро:** двойной клик по `index.html`.

**Правильно (рекомендую):** через локальный сервер — так браузер гарантированно
сохраняет данные между запусками:

```bash
cd slate-app
python3 -m http.server 8000
```

Затем откройте http://localhost:8000 и добавьте страницу в закладки.

Разница важна: при открытии файла напрямую (`file://`) некоторые браузеры,
в первую очередь Safari, не дают сохранять данные — записи пропадут после закрытия
вкладки. Если это так, программа сама покажет предупреждение сверху. В Chrome
двойной клик обычно работает нормально.

## Что умеет

**Сегодня** — занятия на сегодня в одно касание («Проведено»), сводка недели, доход
за месяц, список тех, у кого заканчиваются оплаченные занятия или появился долг.

**Расписание** — неделя целиком, листается стрелками. Занятие переносится
перетаскиванием на другой день. Клик по занятию открывает карточку: провести,
не пришёл, отменить, изменить время, удалить.

**Ученики** — карточка на каждого: предмет, уровень, ставка, контакт, родитель,
заметки. Внутри — баланс, ближайшие занятия, история и оплаты. Кнопка «Текст для
ученика» готовит сообщение с остатком и ближайшими занятиями — скопировать
и отправить в мессенджер.

**Оплаты** — записываете пакет («8 занятий»), сумма подставляется из ставки ученика.
Баланс считается сам: оплачено минус проведено. Долг подсвечивается красным.

**Отчёты** — доход по месяцам, проведённые занятия, часы и таблица по ученикам.

**Настройки** — язык, валюта, ставка и длительность по умолчанию, правило
«неявка считается проведённым занятием», экспорт и импорт данных, демо-данные.

## Данные

Всё хранится в браузере на вашем компьютере — никакого облака, никто ничего не видит.
Поэтому:

- **Настройки → Выгрузить в файл** делает бэкап `slate-YYYY-MM-DD.json`. Делайте
  это хотя бы раз в неделю.
- **Загрузить из файла** восстанавливает данные — в том числе на другом компьютере.
- Данные привязаны к конкретному браузеру: в Chrome и Safari будут разные базы.

## Как начать

1. Настройки → **Загрузить демо-данные**, чтобы посмотреть, как всё выглядит.
2. Настройки → **Стереть всё**.
3. Добавьте своих учеников, запишите их текущие оплаты — и разложите неделю.

Занятие списывается с баланса в момент, когда вы отмечаете его проведённым,
а не когда оно стоит в расписании.
