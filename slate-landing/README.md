# Slate — лендинг для репетиторов и частных преподавателей

Одностраничный сайт на трёх языках (English / Русский / Հայերեն) в бежево-оливковой гамме.
Весь сайт — один файл `index.html`: вёрстка, стили, переводы и скрипты внутри,
внешних запросов нет, поэтому страница полностью работает офлайн.

## Как открыть на макбуке

Дважды кликнуть по `index.html` — откроется в браузере.

Локальный сервер (например, чтобы посмотреть с телефона в той же сети):

```bash
cd slate-landing
python3 -m http.server 8000
```

Затем http://localhost:8000

## Три языка

Переключатель EN / RU / ՀԱՅ стоит в шапке. Логика:

- при первом заходе язык определяется по языку браузера (`hy` → армянский, `ru` → русский, иначе английский);
- выбор запоминается в `localStorage` под ключом `slate-lang`;
- при переключении меняются тексты, `<html lang>`, `<title>` и meta-описание.

Все тексты лежат в одном объекте `T` в конце файла — ключ и три языка рядом:

```js
"hero.cta1":{en:"Start free",ru:"Начать бесплатно",hy:"Սկսել անվճար"},
```

В разметке элемент подписан атрибутом `data-i18n="hero.cta1"` (или `data-i18n-html`,
если внутри есть теги). Чтобы поменять текст — правите одну строку в `T`, ничего
искать по вёрстке не нужно. Сейчас переведено 246 элементов, пропусков нет.

Для армянского отдельно уменьшен кегль заголовков и подобран шрифтовой стек
(`Noto Sans Armenian`, `Mshtakan`), потому что армянские слова заметно длиннее.

| Шапка | Логотип, навигация, переключатель языка, «Войти», CTA |

## Палитра и шрифты

Цвета — CSS-переменные в начале файла (`:root`), меняются в одном месте:

```
Бежевые:   #FBF8F1  #F4EFE3  #EAE3D2  #DED5BF
Оливковые: #EDF0E2  #DDE3CB  #C3CDA6  #A2B07E  #7F9159  #657646  #4F5D34  #3A4429  #2B331F
Текст:     #23261C  #484D3C  #787D68
Акцент:    #B4835B (глина, для пробных занятий)
```

Шрифты системные: заголовки — Iowan Old Style (есть на macOS), интерфейс — SF Pro / Inter,
армянский — Noto Sans Armenian. Ничего не подгружается из интернета.

## Что заменить перед публикацией

- **Цены** в тарифах ($0 / $9 / $29) — демонстрационные.
- **Цифры** в блоке статистики и **отзыв** — тоже демонстрационные.
- Имена учеников в макетах (Мари, Лёва, Арам, Тигран, Нина) — вымышленные.
- **Армянские тексты** стоит вычитать носителю языка: смысл и терминология выверены,
  но живой язык лучше проверить глазами.
