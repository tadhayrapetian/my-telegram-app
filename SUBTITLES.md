# Автосубтитры для сторис (армянский · русский · английский)

Страница `subtitles.html` — полноценный редактор субтитров для вертикальных видео,
заточенный под армянскую речь с переключением на русский и английский внутри одного ролика.

Открывается по адресу вида `https://<ваш-домен>/subtitles.html`, работает и в браузере,
и внутри Telegram Mini App. Ничего устанавливать не нужно, весь монтаж идёт в браузере.

## Что умеет

- **Распознавание с пословными таймкодами.** Каждое слово получает своё время начала и конца —
  отсюда точная синхронизация и подсветка «караоке».
- **Смешанная речь.** В режиме языка «Авто» армянские слова пишутся армянскими буквами,
  русские — кириллицей, английские — латиницей, ровно так, как они прозвучали.
  Жёсткий выбор языка нужен только если ролик строго одноязычный.
- **Два движка на выбор:**
  - **ElevenLabs Scribe** (`scribe_v1`) — заметно лучше остальных справляется с армянским
    и с переключением языков;
  - **OpenAI Whisper** (`whisper-1`) — запасной вариант, поддерживает поле «подсказка»
    с именами собственными.
- **Длинные видео** автоматически режутся на части по паузам, таймкоды потом склеиваются.
- **Полная настройка внешнего вида:** гарнитура (включая загрузку своего `.ttf`/`.otf`),
  размер, насыщенность, курсив, ЗАГЛАВНЫЕ, межбуквенный и межстрочный интервал,
  цвет и прозрачность текста, обводка, тень, плашка (на блок / на строку / на слово),
  положение по вертикали и горизонтали, ширина блока, число строк,
  анимация появления (плавно / подскок / снизу вверх / слово за словом),
  подсветка текущего слова, увеличение активного слова, плашка под активным словом.
- **Пресеты оформления** — пять готовых и любое количество своих (хранятся в браузере).
- **Редактор реплик:** правка текста, точные тайминги, «начало/конец по текущему кадру»,
  разделение, склейка, добавление и удаление реплик.
- **Словарь автозамен** — чтобы повторяющаяся ошибка распознавания (имя, название канала)
  чинилась один раз и навсегда.
- **Экспорт:** `SRT`, `VTT`, `ASS` (с шрифтом, цветами, обводкой, плашкой и караоке),
  проект `JSON`, а также запись готового видео с вшитыми субтитрами прямо из браузера.

## Как пользоваться

1. Откройте `subtitles.html`, перетащите видео в окно превью.
2. Вкладка **«Распознавание»** → выберите движок и вставьте API-ключ.
   Ключ хранится только в `localStorage` вашего браузера и уходит исключительно
   на выбранный сервис распознавания.
3. Язык оставьте **«Авто»**, если в ролике вы переключаетесь между языками.
4. Нажмите **«Распознать речь»**.
5. Вкладка **«Разбивка»** — сколько слов и символов в реплике, по каким паузам рвать,
   общий сдвиг таймкодов.
6. Вкладка **«Стиль»** — оформление; всё видно в превью в реальном времени.
7. Поправьте текст в списке реплик, если что-то распозналось не так.
8. Вкладка **«Экспорт»** — забрать файл субтитров или записать видео с вшитыми субтитрами.

## Экспорт и монтаж

| Формат | Когда нужен |
| --- | --- |
| `ASS` | Максимальное качество. Сохраняет шрифт, цвета, обводку, плашку, положение и караоке. Понимают CapCut (desktop), Premiere, DaVinci Resolve, VLC, ffmpeg. |
| `SRT` | Простой текст без оформления — для Telegram, YouTube, Instagram, авто-титров. |
| `VTT` | То же самое для веб-плееров. |
| `JSON` | Проект целиком (реплики + стиль), чтобы вернуться к работе позже. |

Вшить `ASS` в видео через ffmpeg:

```bash
ffmpeg -i video.mp4 -vf "ass=subs.ass" -c:a copy out.mp4
```

## Запись видео прямо в браузере

Кнопка «Записать видео с субтитрами» рисует кадр вместе с субтитром на canvas и пишет
результат через `MediaRecorder` вместе со звуком.

- Запись идёт **в реальном времени**: ролик на 30 секунд пишется 30 секунд.
  Вкладку в это время сворачивать нельзя.
- Формат зависит от браузера: в свежем Chrome получается MP4 (H.264), иначе WebM.
- Для идеального качества всё же лучше экспортировать `ASS` и вшить его через ffmpeg
  или в монтажной программе — там перекодирование без потерь по времени.

## Технические детали

- `subtitles/js/audio.js` — извлечение звука через Web Audio, приведение к моно 16 кГц,
  упаковка в WAV, нарезка длинных дорожек по тишине.
- `subtitles/js/asr.js` — обращение к ElevenLabs / OpenAI, склейка таймкодов кусков.
- `subtitles/js/text.js` — словарь автозамен, сборка слов в реплики, парсер SRT/VTT.
- `subtitles/js/renderer.js` — отрисовка субтитра на canvas (общая для превью и записи,
  поэтому превью и результат совпадают точь-в-точь).
- `subtitles/js/exporters.js` — SRT / VTT / ASS / JSON.
- `subtitles/js/burn.js` — запись видео через `MediaRecorder`.
- `subtitles/js/store.js` — состояние, настройки, пресеты.
- `subtitles/js/app.js` — интерфейс.

Внешних зависимостей нет, сборка не нужна — это статические файлы.

## Если что-то не работает

- **«Браузер не смог декодировать звук»** — сконвертируйте видео в MP4 с AAC-звуком
  или загрузите отдельную аудиодорожку (`m4a`, `mp3`, `wav`).
- **Ошибка 401/403** — неверный API-ключ.
- **Запрос заблокирован (CORS)** — во вкладке «Распознавание» → «Продвинутые настройки»
  можно указать адрес своего прокси вместо адреса API.
- **Кнопка записи видео недоступна** — браузер не поддерживает `MediaRecorder`
  (частая история на iOS). Экспортируйте `ASS`/`SRT`.
- **Армянский текст в экспортированном файле выглядит квадратами** — в плеере или монтажке
  не установлен шрифт с армянскими буквами; поставьте Noto Sans Armenian.
